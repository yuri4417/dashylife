# Prévia de design do DashyLife

Abra `index.html` em um navegador ou, a partir da raiz do projeto, execute:

```sh
python3 -m http.server 4174 --directory design-preview
```

Acesse <http://localhost:4174>. Use o seletor no topo para comparar as três propostas na mesma tela. A navegação, a busca, os filtros, as tarefas e os formulários são demonstrativos. As alterações existem apenas na memória da página e desaparecem ao recarregá-la; os controles de configurações são ilustrativos. A prévia não acessa a API, o banco de dados ou as configurações do DashyLife.
